# Splitwise: An expense tracking application (WIP: 👷🔧)
- A RESTFUL API application to track expenses and transactions.
- Currently, this is a backend application, Frontend - future scope.
- Built using SpringBoot
Connected to MySQL database

### Functional Requirements
- Create users.
- Allow users to create groups and add user to it.
- Allow users to add expenses to the group, including/excluding some people from it
- Allow them to edit expenses
- Simplifying expenses: minimise the number of transactions made
- Settle up transactions: pay owed amount.

### Core Entities
- User 
- Group
- Expense
- Transaction. (To be mimicked by Expense)
